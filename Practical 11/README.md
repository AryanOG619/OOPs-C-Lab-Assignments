# Practical 11 – Standard Template Library (STL)

## Aim
To implement and understand the List and Vector containers of the Standard Template Library (STL) in C++.

## Problem Statement
Develop a C++ program for an Event Management System using STL containers. The program manages event participants using a List container and event activities using a Vector container. It performs insertion, deletion, traversal and size operations.

## Concepts Used
- Standard Template Library (STL)
- List Container
- Vector Container
- `push_back()`
- `push_front()`
- `remove()`
- `insert()`
- `erase()`
- `size()`
- Range-based For Loop

## Program Description

### Part A: List Container
- Creates a list of event participants.
- Adds participants using `push_back()` and `push_front()`.
- Removes Rahul using `remove()`.
- Displays the remaining participants.
- Displays the total number of participants using `size()`.

### Part B: Vector Container
- Creates a vector of event activities.
- Adds activities using `push_back()`.
- Inserts Inauguration at the beginning using `insert()`.
- Removes Workshop using `erase()`.
- Displays the remaining activities.
- Displays the total number of activities using `size()`.

## Sample Output

```text
Event participants (list):
Karan
Aditi
Sana
Total participants: 3

Event activities (vector):
Inauguration
Registration
Seminar
Total activities: 3
```

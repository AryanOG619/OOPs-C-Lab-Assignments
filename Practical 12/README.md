# Practical 12 – Type Casting

## Aim
To implement different type casting operators in C++.

## Concepts Implemented
- static_cast
- dynamic_cast
- const_cast
- reinterpret_cast
- Inheritance
- Virtual functions
- Runtime type checking

## Problem Statement
Develop a C++ program for a Vehicle Rental Management System demonstrating different type casting operators to perform type conversion, access derived class functionality, modify variable values and convert memory addresses into integer representations.

## Technologies Used
- Programming Language: C++
- IDE: Dev-C++
- Header Files: iostream, cstdint

## Program Description
The program demonstrates four casting operators:

1. **static_cast:** Converts the daily rental rate from double to int.
2. **dynamic_cast:** Converts a base class pointer into a derived class pointer safely.
3. **const_cast:** Removes constness from a reference to modify the original variable.
4. **reinterpret_cast:** Converts a variable's memory address into an integer representation.

## Expected Output
```text
Daily rental rate (whole rupees): 1499
Vehicle type: Electric car
Battery range: 420 km
Updated seat capacity: 7
Seat variable address as integer: [System-dependent address]
```

## Learning Outcomes
- Understood different type casting operators in C++.
- Implemented safe runtime type conversion using dynamic_cast.
- Learned how const_cast and reinterpret_cast work.
- Applied type casting concepts in a Vehicle Rental Management System.

## Conclusion
Successfully implemented and demonstrated all four major type casting operators in C++ through a real-world Vehicle Rental Management System.
